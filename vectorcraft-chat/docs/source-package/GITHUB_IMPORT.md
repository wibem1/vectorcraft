# GitHub-Import

Zielrepository: `wibem1/VectorCraft-Chat` (separat vom vorhandenen `wibem1/vectorcraft`).

1. Auf GitHub ein **leeres** Repository `VectorCraft-Chat` unter `wibem1` anlegen.
2. Dieses Paket vollständig entpacken. Terminal im entpackten Ordner öffnen.
3. `git init && git add . && git commit -m "Initial documentation and VectorCraft Chat 0.1.1"`
4. `git branch -M main`
5. `git remote add origin https://github.com/wibem1/VectorCraft-Chat.git`
6. `git push -u origin main`

Das ZIP ist als Importvorlage erstellt; es ist noch kein GitHub-Commit. Nur ausgeführt melden, wenn Push tatsächlich bestätigt ist.
